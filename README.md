## ✦ О проекте

Этот сайт — личная творческая визитка и небольшой видеоархив. Здесь собраны три направления, которыми я занимаюсь: **вокал, игра на гитаре и танцы**, а также записи выступлений и репетиций.

Проект начинался как дополнение к видеовизитке для конкурса «Мисс и Мистер РТУ МИРЭА», но задуман как пространство, которое можно пополнять и развивать дальше.

## 01 / Направления

| Вокал | Гитара | Танцы |
|:---|:---|:---|
| 11 лет занятий, сольные и хоровые выступления | Аккомпанемент и выступления с гитарой | Бальные танцы и латина-хорео |

## 02 / Дизайн

**Визуальный язык:** мягкая сиренево-розовая палитра, кремовая основа, контрастная типографика и акцентные графические детали.

- **Типографика:** Unbounded + Manrope
- **Цвета:** `#F6F3EE` · `#231F2F` · `#B9A5EE` · `#F5A4AC`
- **Принципы:** адаптивность, простая навигация, акцент на реальных фото и видео

## 03 / Технологии

`HTML` · `CSS` · `JavaScript` · `GitHub Pages`

Без фреймворков и сборщика: сайт можно открыть локально и обновлять обычным `git push`.

```text
personal-site/
├── index.html          # Разметка страницы
├── style.css           # Основные стили
├── custom.css          # Дополнительные стили
├── site-config.js      # Выступления и контакты
├── script.js           # Карточки и ссылки
├── assets/             # Фото, обложки и SVG
└── .nojekyll           # Публикация без Jekyll
```

<details>
<summary><b>Как запустить локально</b></summary>

Открой проект в WebStorm и запусти `index.html` через **Open in Browser**. Также можно поднять локальный сервер:

```bash
python3 -m http.server 8000
```

Затем открой `http://localhost:8000/`.

</details>

<details>
<summary><b>Как обновить сайт</b></summary>

Тексты карточек, ссылки на выступления и контакты меняются в `site-config.js`. Изображения хранятся в `assets/`.

```bash
git add .
git commit -m "Update personal site"
git push
```

GitHub Pages публикует содержимое ветки `main` из корня репозитория.

</details>

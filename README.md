# Творческая страница Екатерины Петренко

Готовый статический сайт для GitHub Pages. Сборка, Node.js и платный хостинг не требуются.

## Перед публикацией

1. Откройте `site-config.js`.
2. Проверьте, что `IMG_1113.MOV` — нужный файл для сольного вокала, а `IMG_0788.MOV` — для гитары. Если наоборот, поменяйте URL и названия.
3. Уберите записи, которые не использовались в видеовизитке, или добавьте другие записи, которые использовались, по аналогии с существующими элементами `recordings`.
4. Добавьте Telegram и VK в `contacts`, например `telegram: 'https://t.me/username'` и `vk: 'https://vk.com/username'`. Пока поля пустые, кнопки не отображаются.
5. Проверьте каждую ссылку на Google Диск в режиме инкогнито: на файлах должен быть доступ «Все, у кого есть ссылка» / просмотр.

## Публикация на GitHub Pages

Выбранное имя репозитория: **personal-site**.
При размещении в GitHub-аккаунте `CatherineFlower` запланированный адрес:

`https://catherineflower.github.io/personal-site/`

1. Перейдите на https://github.com/new
2. Repository name: `personal-site`, visibility: **Public**, Create repository.
3. Распакуйте ZIP; загрузите в корень репозитория файлы `index.html`, `style.css`, `site-config.js`, `script.js`, `.nojekyll` и каталог `assets/` с сохранением структуры. В браузере GitHub можно выбрать **Add file → Upload files** и перетащить все файлы и каталог, затем **Commit changes**.
4. Перейдите в **Settings → Pages → Build and deployment**, выберите **Deploy from a branch**, branch **main**, folder **/(root)**, сохраните.
5. После публикации откройте страницу по ссылке и протестируйте на телефоне. QR-коды в этом комплекте ведут на запланированный адрес, поэтому **не вставляйте их в финальное видео до проверки открывающейся страницы**.

Сайт опубликован в открытом доступе и показывает имя, вуз и указанные видео — перед публикацией проверьте согласие на размещение групповых записей и отсутствие персональных данных, которыми не хотите делиться.

## Содержимое

- `index.html` — страница
- `style.css` — оформление и адаптивность
- `site-config.js` — данные записей и контакты
- `script.js` — генерация карточек
- `assets/*.webp` — обложки из ваших исходных выступлений
- `.nojekyll` — публикация статических файлов без Jekyll
